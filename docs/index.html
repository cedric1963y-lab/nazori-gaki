なぞり書き

サポート

対象は iPhone アプリ「ご祝儀袋・香典袋 なぞり書き」（ホーム画面の名前は「なぞり書き」、Bundle ID jp.nazorigaki.app）です。最終更新: 2026年10月8日。

ご祝儀袋や香典袋の表書きと名前を、iPhone の画面に実寸の筆文字で表示するアプリです。袋の短冊や中袋、薄い紙を画面に重ねて、上から筆ペンでなぞって書けます。アカウントはありません。

使い方

  1. ホームで用途（結婚祝い・香典・法事・御見舞・御礼・お年玉など）を選びます。
  2. 表書きを選び、お名前を入力します。姓と名の間にスペースを入れると、少し間をあけて表示します。
  3. 袋の大きさと墨の色（濃墨・薄墨）を選び、「なぞり書きを始める」を押します。
  4. 上部の「表書き」「お名前」で表示を切り替えます。ドラッグで位置、2本指や −／＋ で大きさを調整できます。
  5. 紙を重ねて「画面を固定してなぞる」を押し、筆ペンで軽くなぞります。長押しで操作に戻ります。

表示中は画面の明るさが最大になり、自動で消えません。画面を離れると元に戻ります。文字の大きさがずれるときは「設定」→「実寸の調整」で、カードの大きさに合わせてください。

無料と全機能アンロック

無料のままでも、楷書の筆文字・1名分のお名前・すべての用途の表書きで使えます。

アプリ内課金「全機能アンロック」（買い切り）を購入すると、書体の追加（4種）、連名（3名まで）、中袋の住所とお名前、金額の大字変換（例: 30000 → 金参萬圓）、名前と住所の履歴が使えます。サブスクリプションではなく、追加の支払いはありません。無料利用時は画面下に広告が表示され、購入後は広告なしになります。

機種変更や再インストールのあとは、アプリの「設定」→「購入を復元」で、同じ Apple ID の購入を呼び戻せます。

データの扱い

入力したお名前や住所は、この iPhone の中だけに保存します。運営のサーバーへは送りません。詳しくは プライバシーポリシー をご覧ください。

書体について

書体は SIL Open Font License 1.1 で公開されているフォント（Yuji Syuku、Yuji Boku、Yuji Mai、Zen Kurenaido、Klee One）を使っています。ライセンス本文はアプリの「設定」→「フォントのライセンス」で読めます。
