なぞり書き

プライバシーポリシー

対象は iPhone アプリ「ご祝儀袋・香典袋 なぞり書き」（Bundle ID jp.nazorigaki.app）です。最終更新: 2026年10月8日。

ご祝儀袋・香典袋 なぞり書き（以下「本アプリ」）は、入力されたお名前・住所・金額・表書きなどを、この iPhone の中だけで扱います。

  • アカウント登録はありません
  • 運営のサーバーへ、入力内容や利用状況を送りません
  • 広告 SDK、解析 SDK は入れていません

収集する情報

開発者が利用者の情報を収集することはありません。入力した内容は、画面に文字を表示するためだけに使われます。

端末内に保存する情報

全機能アンロック後の「名前と住所の履歴」、書体や袋の大きさの設定、実寸の調整値、購入済みかどうかの記録を、この iPhone の中（アプリの保存領域）に保存します。本アプリを削除すると、これらも消えます。iPhone のバックアップをオンにしている場合、Apple のバックアップに含まれることがあります。

購入

アプリ内課金の購入と確認は Apple の App Store（StoreKit）が行います。支払い情報を本アプリや開発者が受け取ることはありません。

トラッキングと広告

トラッキングはしません。広告識別子も広告 SDK も使いません。このウェブページも、解析用のスクリプトや第三者への送信をしません。

使わない権限

位置情報、カメラ、写真ライブラリ、連絡先、マイク、健康情報は使いません。画面の明るさの変更と自動ロックの一時停止は、なぞり書きの画面を表示している間だけ行います。
